# Molecule Search API

Небольшое приложение для хранения молекул и поиска по субструктуре.

Молекула задается строкой SMILES. Поиск работает через RDKit.

## Что сделано

- добавление молекул
- просмотр списка молекул
- просмотр молекулы по id
- обновление молекулы
- удаление молекулы
- поиск молекул по субструктуре
- проверка SMILES перед сохранением
- пагинация списка молекул
- простой сайт для работы через браузер
- Swagger UI для проверки API

## Технологии

- FastAPI - backend
- PostgreSQL - база данных
- SQLAlchemy - работа с базой из Python
- RDKit - проверка SMILES и поиск по субструктуре
- Redis - кеш для результатов поиска
- Docker Compose - запуск всех сервисов одной командой

## Запуск

В корне проекта выполнить:

```bash
docker compose up --build
```

После запуска открыть сайт:

```text
http://127.0.0.1:8000
```

Swagger UI:

```text
http://127.0.0.1:8000/docs
```

## Основные API endpoints

- `POST /molecules` - добавить молекулу
- `GET /molecules` - получить список молекул
- `GET /molecules/{molecule_id}` - получить молекулу по id
- `PUT /molecules/{molecule_id}` - обновить молекулу
- `DELETE /molecules/{molecule_id}` - удалить молекулу
- `POST /search` - поиск по переданному списку SMILES
- `POST /search/database` - поиск по молекулам из базы

## Как работает кеш

Для повторяющихся поисковых запросов используется Redis.

Если один и тот же поиск выполняется повторно, результат может быть взят из кеша.  
Если молекула добавляется, обновляется или удаляется, кеш очищается.

В ответе `/search/database` поле `source` показывает, откуда взят результат:

```json
{
  "source": "database"
}
```

или

```json
{
  "source": "cache"
}
```

## Примеры для проверки

Молекулы:

```text
CCO - ethanol
c1ccccc1 - benzene
CC(=O)O - acetic acid
CC(=O)Oc1ccccc1C(=O)O - aspirin
```

Пример субструктуры для поиска бензольного кольца:

```text
c1ccccc1
```

Ожидаемый результат: будут найдены молекулы, содержащие бензольное кольцо, например benzene и aspirin.
